# 講師育成研修（90分）アウトライン ver.3

対象事業：兵庫県 令和8年度 健康づくり研修会支援事業
受講対象：グンゼスポーツと契約するフリーランスインストラクター 8名
実施形態：8名それぞれ個別に実施（1対1／90分）→ 数日後に個別チェック（60分）
講座数：**全10講座**（LPに掲載の内容が正）

---

## 1. 今回の前提（ver.1からの変更点）

| 項目 | 内容 |
|------|------|
| 講座数・内容 | 全10講座。LPの記載が正とする |
| 担当講座 | 各インストラクターが**自分の得意分野・実施可能な講座のみ**を担当。10講座すべて可の人もいれば、2〜3講座のみの人もいる |
| 事前課題 | **なし**。資料が膨大で、事前学習の負担が大きすぎるため |
| 学習の順番 | 90分研修を受ける → **その場で担当講座を選ぶ** → 選んだ講座だけを勉強 → 数日後にチェック |
| 60分チェック | **落とすためのものではない**。研修担当者として過不足がないかを確認するもの。結果によって担当を外すことは原則しない |
| 受講者の特性 | 普段はエクササイズ指導が中心。**机上での説明が多い研修形式には慣れていない** |
| 実技の扱い | 全体の流れは共通のまま、**実技パートは各インストラクターの得意分野に任せる** |
| 講座資料 | 別冊の講師台本はない。**各講座の資料（テキスト）を読みながら進められる**形式 |

## 2. 設計方針

| # | 方針 | 理由 |
|---|------|------|
| ① | **「説明パートは公式資料どおり／実技パートはあなたに任せる」** を冒頭で宣言する | 受講者の最大の不安は「机上の説明ができるか」。役割分担を最初に示すことで、90分を防御的にではなく前向きに受けてもらえる |
| ② | 事前課題ゼロ。**90分は手ぶらで来て完結する構成** にする | 資料の総量が多く、事前学習を課すと着手のハードルが上がる。持ち帰り学習は「選んだ講座の分だけ」に絞る |
| ③ | 10講座は **「覚えるため」ではなく「選ぶため」** に紹介する | 全講座の中身を90分で頭に入れるのは不可能。判断に必要な情報（誰向け・時間・実技の量・必要資格）だけを渡す |
| ④ | 90分の主役は **実演30分**。しかもうち10分は「初見の講座テキストを読みながら進める」練習 | 予習なしでも講座資料があれば進行できる、という体験そのものが最大の不安解消になる |
| ⑤ | 90分の成果物＝**その人の担当講座リスト** | 研修の終わりに担当が決まることで、翌日からの学習対象が明確になり、負担感が具体的に下がる |
| ⑥ | 60分チェックは **合否判定ではなく「補強点の洗い出し」** として設計・呼称する | 落とすものではない以上、名称・進行・結果通知のすべてを「確認とサポート」の言葉で統一する |

### 到達目標（この90分のゴール）
1. 県の受託事業としてのルール（禁止事項・KPI・アンケート）を理解している
2. 講座資料（テキスト）の使い方が分かり、**初見でも読みながら説明パートを進行できる**
3. 実技パートを自分の得意分野で組み立てられ、その際の3条件（狙い・安全・時間）を守れる
4. **自分が担当する講座を確定させている**

## 4. ブロック別 詳細アウトライン

### ブロック0：オープニング（5分／0:00–0:05）
- **目的**：不安を先回りして取り除き、この90分の受け方を決めてもらう
- **内容**
  1. 冒頭で必ず伝える3つ（この研修の"憲法"）
     - **予習は不要**。今日は手ぶらでよい
     - **説明パートは講座資料（テキスト）を読みながら進めてよい**。ゼロから作る必要はない
     - **実技パートはあなたの得意分野に任せる**。普段やっている指導がそのまま強みになる
  2. 持ち帰って勉強するのは、**今日選んだ講座の分だけ**であることを明示
  3. ヒアリング：普段の指導内容、得意な種目・分野、対面／オンラインの経験、人前での説明の経験
- **到達確認**：受講者から「それならできそう」という反応が出ているか（出ていなければ①を言い直す）

### ブロック1：事業理解とルール（13分／0:05–0:18）
- **目的**：民間レッスンではなく県の受託事業であることを理解してもらう
- **内容**
  1. 事業の背景と目的（在宅勤務増加による活動量低下／働き盛り世代の健康づくり）
  2. 枠組み（健康づくりチャレンジ企業が対象、1回概ね2時間、1社あたり累計3回まで、県下全域が対象）
  3. **禁止事項（ここだけは絶対）**
     - 受講料・相談料・テキスト代等の徴収は一切不可
     - 自社商品・自社事業の営業、広告宣伝、利益誘導は不可
     - 資料・案内物には県からの受託事業である旨を明記
  4. KPIと効果測定（週1回以上運動する人の割合60%以上／研修前・1ヶ月後のアンケート）
     - 「アンケートは事務作業ではなく成果指標そのもの」
  5. 研修終了後に個別質疑応答の時間を必ず設けること
- **手法**：最後に〇×クイズ5問でその場確認（設問はそのまま60分チェックでも使用し、事前に「ここは聞きます」と伝える）
- **到達確認**：禁止事項3点を見ずに言えるか

### ブロック2：10講座の全体像と仮の仕分け（15分／0:18–0:33）
- **目的**：覚えてもらうのではなく、**自分が担当できる講座を見極めてもらう**
- **内容**
  1. 3区分（ア.運動習慣／イ.食生活／ウ.健康意識・行動変容）と10講座の一覧を1枚で提示
  2. 1講座あたり60〜90秒で、**選ぶために必要な情報だけ**を通す
     - 誰向けか／所要時間・形式（対面・オンライン・オンライン限定・個別30分）／実技の比率／必要な知識・資格／使用機材
  3. 特に確認が必要な講座を明示
     - 食生活系（4・5）は栄養に関する知識が必要 → 該当資格の有無を確認
     - 測定系（6・7）は機器の扱いと個別フィードバックが必要 → 対面のみ・定員20名
     - 5日間ストレッチチャレンジ（3）はオンライン限定・1回15分×5日の連続実施
     - 女性向け講座（10）は担当者の適性・本人の希望を尊重
  4. 受講者がその場で **◎できる／△要相談／✕今回は外す** の3分類を仮マーク
- **手法**：一覧表に本人が直接マークする（この紙がブロック6でそのまま担当リストになる）
- **到達確認**：10講座すべてに仮マークが付いているか

### ブロック3：公式資料の使い方（12分／0:33–0:45）
- **目的**：「机上の説明」への不安を、資料の実物を見せて解消する
- **内容**
  1. 資料の構成を実物で見せる：講座資料（テキスト）／受講者配布物（習慣化シート・持ち帰り資料）
     - どのページに何が書いてあるか、どこを読めばよいかを指で追って示す
     - **別冊の講師台本はない**。この講座資料そのものを読みながら進める形式であることを明確に伝える
  2. **テキストは見ながら話してよい**。読みながら進められるように作ってあることを明言
  3. **変えてよい所／変えてはいけない所**
     | | 内容 |
     |---|---|
     | 変えてよい | 実技の種目、例え話、自分の経験談、進行のテンポ、参加者への声かけ |
     | 変えてはいけない | 数値・出典、禁止事項に関わる表現、習慣化シートの実施、ゴール提示、個別質疑の時間 |
  4. 全講座共通の型：**本日のゴール提示 → 導入（なぜ大事か） → 実践 → 習慣化シート（明日から実践する行動を1つ決定） → 質疑 → まとめ**
  5. 説明パートで守る3つ：**結論から言う／数字は資料の出典どおりに言う／診断・治療の話はしない**
  6. 時間が押した時に削る所・絶対削らない所（削らない：ゴール提示・習慣化シート・個別質疑）
- **到達確認**：「この講座の実技を自分の種目に差し替えるとしたらどこか」を指させるか

### ブロック4：実演（30分／0:45–1:15）★この研修の本体

#### 4-A　説明パートの実演（10分）
- **その場で渡した講座テキストの1ページを、初見で3分読みながら進める**
- 目的は上手さではなく「予習なしでも進行できる」という**体験**
- フィードバックは3点に限定：声の大きさ・スピード／顔を上げるタイミング／スライドと話の同期
- 指摘を反映して同じ箇所を1分リテイク

#### 4-B　実技パートの実演（12分）
- **受講者の得意分野で3〜5分、内容は完全にお任せ**（普段やっている指導でよい）
- フィードバックは"うまさ"ではなく、企業研修で必要になる次の観点に絞る
  1. 開始前の体調確認の声かけがあるか
  2. **座ったままできる代替種目**を提示できるか（オフィス・服装・靴・スペースの制約）
  3. 痛みが出た場合の中止指示を言えるか
  4. オンライン時にカメラで全身が見える位置取りができるか
  5. 時間内に収まっているか
- **実技を任せる際の3条件**（ここを守れば種目は自由）
  - ① その講座の狙いから外れない（例：肩こり講座で高強度の全身運動をしない）
  - ② 座位での代替を必ず用意する
  - ③ 決められた時間内に収める

#### 4-C　つなぎの練習（8分）
- **説明 → 実技 → 説明に戻る** 接続部分の言葉を練習する（最も崩れやすい箇所）
- 型を渡す
  - 説明→実技：「では、実際にやってみましょう。まず私がやります。無理のない範囲で結構です」
  - 実技→説明：「はい、ありがとうございます。今やっていただいた動きが、なぜ効くかというと——」
- 実技の後に必ず**習慣化シートへつなげる**言い回しを1つ固定で持たせる

### ブロック5：安全管理と当日実務（9分／1:15–1:24）
- **目的**：事故とクレームを防ぎ、起きた時に正しく動けるようにする
- **内容**
  1. **医療行為との線引き**：診断・治療・個別の治療指示は行わない。症状が強い方への案内は**固定フレーズ**で持たせる
  2. 実施前の安全確認：体調確認、既往歴・妊娠中・痛みのある方への代替種目、実施環境（床・靴・スペース・椅子の安定）
  3. 急変・負傷時：中止 → 安全確保 → 企業担当者へ連絡 → 救急要請の判断 → 事務局へ報告（連絡先1枚を携行）
  4. 産業医との事前相談・連携が必要なケース
  5. 個人情報：測定結果・健診情報・撮影の取り扱い、SNS投稿の禁止
  6. 当日実務：持ち物・機材、開始前の会場／接続確認、資料配布、**アンケート（研修前・1ヶ月後）の実施と回収**、終了後の個別質疑、実施報告
- **手法**：ケース問答3問（腰痛の申告がある／開始5分前に接続できない／終了後に個別の治療相談をされた）
- **到達確認**：3問すべてに正しい初動を答えられるか

### ブロック6：担当講座の確定と次のステップ（6分／1:24–1:30）
- **目的**：この90分の成果物を確定させ、持ち帰り学習の範囲を最小化する
- **内容**
  1. ブロック2の仮マークを見直して **担当講座リストを確定**（△要相談は本人の希望を聞いて決める）
  2. **確定した講座の資料だけを渡す**（全講座分は渡さない＝負担軽減の実装）
  3. 数日後のチェックの案内
     - **合否判定ではなく、過不足の確認である**ことを明言
     - 何を見るか（説明パートの進行／実技／安全対応／ルールの理解）を事前開示
     - 足りない点はチェック後に資料・追加サポートで埋める
  4. 質疑、連絡窓口の確認

## 5. 60分チェック（数日後）の位置づけ

**名称を「テスト」から変える**ことを推奨します。落とすためのものでない以上、呼び方・進行・結果の伝え方をすべて「確認とサポート」で統一した方が、受講者の準備の質が上がります。

> 例：「実施前チェック」「担当前リハーサル確認」「実施準備確認」

### 結果の出し方（"不合格"を作らない3段階）

| 判定 | 意味 | その後の対応 |
|------|------|-------------|
| A. そのまま実施可 | 過不足なし | 単独で担当 |
| B. 補足付きで実施可 | 一部に補強が必要 | 補足資料・追加のテキスト読み合わせを渡して担当 |
| C. 同行サポート付きで実施可 | 初回に不安が残る | 初回のみ同行・オンライン同席の上で担当 |

「担当させない」ではなく「どう支えれば担当できるか」を出力にすることで、チェックの目的（過不足の確認）と一致します。

### 60分の構成（概要案・詳細は別途）

| 時間 | 内容 |
|------|------|
| 10分 | ルール・安全の口頭確認（〇×5問はブロック1と同一設問） |
| 15分 | 担当講座から指定パートの説明を実演 |
| 10分 | 実技パートの実演（本人の組み立てで） |
| 10分 | ケース問答（安全・当日トラブル） |
| 10分 | フィードバックと補強プランの提示（A/B/Cの判定と理由） |
| 5分 | 実施スケジュール・事務連絡 |

## 6. 公式資料（講座資料）側への反映事項

実技を各インストラクターに任せる方針を、**資料の側でも読み取れる形にしておく**必要があります。そうしないと、講師が「資料に載っている種目」と「自分のやり方」の食い違いに悩みます。

1. 実技パートのスライドに **「実技例」「差し替え可」** と明記する（掲載種目は指定ではなく例示であることを示す）
2. 実技パートの冒頭に、その講座の **狙い・想定時間・強度の目安** を1行で記載する（差し替えの判断基準になる）
3. 講座資料（テキスト）の中で **「ここは自由に進めてよい」区間と「読みながら進める」区間** を色分け等で区別する
4. 座位でできる代替種目を、各講座に最低1つは標準で載せておく
5. 数値・出典・禁止事項に関わる記述は「変更不可」と明示する

## 7. 8名を個別実施するための運用メモ

- **育成側の進行台本を1本に固定**：8回の説明内容がブレると、チェックの公平性が崩れる（講座資料とは別物）
- **実施記録を1名1シート**：得意分野、担当講座、実演のフィードバック内容、要補強点を記録し、60分チェックにそのまま引き継ぐ
- **担当講座マトリクスを1枚で管理**：8名×10講座の可否表を作ると、企業からの依頼に対して誰を割り当てられるかが即座に分かる。**どの講座も担当者ゼロにならないか**をこの表で確認する
- **日程**：研修とチェックの間隔は、担当講座の学習時間が取れる3〜7日が目安。担当講座が多い人ほど間隔を長めに
- **担当講座数の偏り**：10講座すべて可の人に依頼が集中しないよう、割り当て時に配慮する

## 8. 確認が必要な事項

1. 資料セットの完成時期（90分研修で実物を見せる必要があるため、少なくとも1講座分は完成している必要がある）
2. 食生活系講座（4・5）を担当できる有資格者が8名の中にいるか。いない場合の対応
3. 測定系講座（6・7）の機器の台数・保管場所・運搬方法
4. 60分チェックの実施者（90分研修の担当者と同一にするか）
5. B・C判定となった場合の同行サポート要員の確保
