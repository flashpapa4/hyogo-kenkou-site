# 講師育成研修（90分）アウトライン

対象事業：兵庫県 令和8年度 健康づくり研修会支援事業
受講対象：グンゼスポーツと契約するフリーランスインストラクター 8名
実施形態：8名それぞれ個別に実施（1対1／90分）→ 数日後に個別テスト（60分）

---

## 1. 設計方針

| # | 方針 | 理由 |
|---|------|------|
| ① | 90分は「知識の伝達」ではなく **「現場の再現」** に使う | 知識インプットは事前課題に前倒しできる。1対1でしか出来ないのはロールプレイと個別フィードバック |
| ② | 90分中 **20分以上を模擬講義＋フィードバック** に確保 | 集合研修では1人あたり数分しか取れない実技を、個別実施の利点として最大化する |
| ③ | 育成側も **台本・チェックリストを固定** して8回実施する | 8名バラバラ実施は内容がブレやすい。テストの評価基準と受けた研修内容が全員同一である必要がある |
| ④ | ゴールは **「数日後の60分テストに合格できる状態」** に置く | 研修→テストが分断されないよう、90分の各ブロックをテストの評価項目と1対1で対応させる |
| ⑤ | 県の受託事業ルール（営業禁止・料金徴収禁止・受託事業の明記）は **必須通過項目** として扱う | 仕様書上の禁止事項に抵触すると事業自体のリスクになるため、理解度が不十分な場合は合格させない |

### 到達目標（この90分のゴール）
1. 兵庫県受託事業としての立ち位置とルール（禁止事項・KPI・報告義務）を自分の言葉で説明できる
2. 標準講座フォーマット（概ね2時間／習慣化シートで行動を1つ決定）の型どおりに講座を進行できる
3. 担当講座の冒頭パートを、企業の受講者を想定して実演できる
4. 安全管理・緊急時対応・個人情報の取り扱いを判断できる

---

## 2. 事前課題（研修日の前日まで／目安30〜40分）

90分を実技に使うため、以下は必ず前倒しで実施する。

| 課題 | 内容 | 提出/確認方法 |
|------|------|--------------|
| A. 事業概要の通読 | 事業目的・対象企業・実施条件・禁止事項のダイジェスト資料 | 研修冒頭で〇×10問により確認 |
| B. 担当講座の通読 | 担当する講座の講師用スライド＋台本 | 研修中の模擬講義で確認 |
| C. 冒頭5分の準備 | 担当講座の「つかみ〜本日のゴール提示」を準備してくる | ブロック4で実演 |
| D. 事前アンケート | 保有資格・指導実績・対面/オンラインの得意不得意・不安な点 | 研修内容の重点配分に反映 |

## 3. 90分の時間割

| 時間 | ブロック | 内容 | 主な手法 |
|------|---------|------|---------|
| 0:00–0:05 | 0. オープニング | 本日のゴール共有／事前課題の答え合わせ | 講義・確認テスト返し |
| 0:05–0:20 | 1. 事業理解とコンプライアンス | 誰の・何のための事業か、やってはいけないこと | 講義＋ケース質問 |
| 0:20–0:35 | 2. 標準講座フォーマット | 全講座共通の「型」と時間配分、習慣化シート | 資料読み合わせ＋時間配分演習 |
| 0:35–0:55 | 3. デリバリー技術 | 自分ごと化させる話法、デモ→実践、対面/オンライン差 | 実演＋部分練習 |
| 0:55–1:15 | 4. 模擬講義＋フィードバック | 担当講座の冒頭を実演→改善点→リテイク | ロールプレイ |
| 1:15–1:25 | 5. 安全管理と実務フロー | 事故・急変・医療との線引き、当日運営とアンケート | ケース問答 |
| 1:25–1:30 | 6. クロージング | テストの案内・宿題・質疑 | 説明 |

---

## 4. ブロック別 詳細アウトライン

### ブロック0：オープニング（5分／0:00–0:05）
- **目的**：この90分で何ができるようになるかを合意する
- **内容**
  - 講師自己紹介・受講者の経歴確認（事前アンケートDの内容を口頭で補足）
  - 本日のゴール4項目の提示
  - 事前課題A（〇×10問）の答え合わせ ※誤答項目はブロック1で重点解説
- **到達確認**：誤答項目の把握（＝この回の重点箇所を決める）

### ブロック1：事業理解とコンプライアンス（15分／0:05–0:20）
- **目的**：「一般の民間レッスン」ではなく「県の受託事業」であることを腹落ちさせる
- **内容**
  1. 事業の背景と目的（在宅勤務増加による活動量低下／働き盛り世代の健康づくり）
  2. 対象と枠組み（健康づくりチャレンジ企業、1回概ね2時間、1社あたり累計3回まで、県下全域が対象で遠方を理由に断らない）
  3. **禁止事項（必須通過項目）**
     - 受講料・相談料・テキスト代等の徴収は一切不可
     - 自社商品・自社事業の営業、広告宣伝、利益誘導は不可
     - 資料・案内物には県からの受託事業である旨を明記
  4. KPI と効果測定（週1回以上運動する人の割合60%以上／研修前・研修1ヶ月後のアンケート）
     - 「アンケートは事務作業ではなく成果指標そのもの」であることを明示
  5. 研修終了後に個別質疑応答の時間を必ず設けること
- **手法**：ケース質問（例：「受講者から自社ジムの体験について聞かれたら？」「企業から追加でパーソナルを頼まれたら？」）
- **到達確認**：禁止事項3点を見ずに言えるか

### ブロック2：標準講座フォーマットの理解（15分／0:20–0:35）
- **目的**：どの講座を担当しても同じ品質・同じ型で進行できるようにする
- **内容**
  1. 全講座共通の骨格
     - 本日のゴール提示 → アイスブレイク → 導入（なぜ大事か） → 実践 → ワーク → 習慣化シート → 質疑 → エンディング
  2. **習慣化シート**の位置づけ（全講座共通で「明日から実践する行動を1つ決定」＝この事業の中核）
     - 抽象的な決意ではなく、行動・頻度・タイミングまで書かせる書かせ方
  3. 時間配分の考え方と、押した場合にどこを削り、どこは絶対に削らないか
     - 削らない：ゴール提示／習慣化シート／個別質疑
     - 調整弁：導入の解説量、実践種目数、コラム
  4. 講座ラインナップ全体像（運動／食生活／健康意識の3区分）と担当講座の位置づけ
- **手法**：担当講座のスライドを開いて、時間配分を実際に割り振らせる（分単位で書き込み）
- **到達確認**：担当講座の時間配分表が自力で完成しているか

### ブロック3：デリバリー技術（20分／0:35–0:55）
- **目的**：「正しい情報を話せる」から「相手が動く」へ引き上げる
- **内容**
  1. 冒頭3分の設計（つかみ → 受講者の現状を挙手やチャットで可視化 → ゴール提示）
  2. 自分ごと化の話法（受講者の職種・作業姿勢・健診結果に紐づけて語る／一般論で終わらせない）
  3. 実践パートの鉄則：**まず講師がデモ → 参加者が実施 → 声かけ・修正**
     - デモ中のカウント、呼吸の指示、痛みが出た場合の中止指示の言い方
  4. 対面とオンラインの違い
     - 対面：立ち位置、机間巡視、見本が見える角度、私語・巻き込み
     - オンライン：カメラ距離と全身の映し方、画面オフ参加者への配慮、チャット活用、通信トラブル時の代替進行
  5. 動かない参加者・反応が薄い場ののさばき方（強制しない／座位で完結する代替種目を必ず用意）
  6. 時間管理（各パートの通過時刻を手元に控える）
- **手法**：講師（育成側）が良い例・悪い例を実演 → 受講者が冒頭3分の一部だけ部分練習
- **到達確認**：デモ→実践の流れを口頭指示付きで再現できるか

### ブロック4：模擬講義＋フィードバック（20分／0:55–1:15）
- **目的**：本番同等の負荷で1回やらせ、改善して定着させる
- **構成**
  | 時間 | 内容 |
  |------|------|
  | 8分 | 事前課題Cで準備した担当講座の冒頭（つかみ〜ゴール提示〜実践1種目のデモ）を実演。育成側は企業の受講者役 |
  | 7分 | フィードバック（評価シートに沿って良い点2つ・改善点2つ、優先度をつけて指摘） |
  | 5分 | 指摘を反映して該当部分のみリテイク |
- **評価シート項目（テストの採点表と同一のものを使用）**
  1. 冒頭で受講者の関心を掴めたか
  2. 本日のゴールを明示したか
  3. 専門用語をかみ砕けたか
  4. デモが見やすく、指示が具体的か
  5. 安全上の注意（痛みが出たら中止等）を伝えたか
  6. 声量・スピード・視線・表情
  7. 時間管理
  8. 禁止事項への抵触がないか
- **到達確認**：リテイクで指摘事項が改善されているか

### ブロック5：安全管理と実務フロー（10分／1:15–1:25）
- **目的**：事故とクレームを起こさない、起きた時に正しく動ける
- **内容**
  1. **医療行為との線引き**：診断・治療・個別の治療指示は行わない。症状が強い受講者は医療機関・産業医へ案内する言い回しを固定文で持たせる
  2. 実施前の安全確認：体調確認の声かけ、既往歴・妊娠中・痛みがある人への代替種目、実施環境（床、靴、スペース、椅子の安定）
  3. 急変・負傷時の対応フロー：中止 → 安全確保 → 企業担当者へ連絡 → 救急要請の判断 → 事務局へ報告（連絡先を明記した1枚を携行）
  4. 産業医との事前相談・連携が必要になるケース
  5. 個人情報：測定結果・健診情報・撮影の取り扱い、企業内での結果の共有範囲、SNS投稿の禁止
  6. 当日実務：持ち物・機材、開始前の会場/接続確認、資料配布、**アンケート（研修前・1ヶ月後）の実施と回収**、終了後の個別質疑、実施報告の提出
  7. 遅延・欠席・悪天候時の連絡ルート
- **手法**：ケース問答3問（例：「腰に痛みがあると申告した人がいる」「開始5分前に接続できない」「終了後に個別の治療相談をされた」）
- **到達確認**：3問すべてに正しい初動を答えられるか

### ブロック6：クロージング（5分／1:25–1:30）
- **目的**：テストまでの数日を空白にしない
- **内容**
  - 数日後の60分テストの案内（実技審査＋確認テスト、評価基準はブロック4の評価シートと同一である旨）
  - 宿題：担当講座を通しで1回自主リハーサル、時間配分表の完成、習慣化シートの記入例を1つ作成
  - 質疑応答、連絡窓口の確認

---

## 5. 60分テスト（数日後）との接続

90分研修の各ブロックが、テストのどの項目に対応するかを事前に受講者へ開示する。

| 90分研修 | 60分テストでの確認方法（案） |
|----------|--------------------------|
| ブロック1 事業理解・禁止事項 | 筆記（禁止事項・KPI・報告義務） |
| ブロック2 標準フォーマット | 筆記＋提出物（時間配分表） |
| ブロック3・4 デリバリー | 実技審査（担当講座から指定パートを実演） |
| ブロック5 安全・実務 | ケース問答（口頭試問） |

※テスト側の詳細設計は別途作成する。

---

## 6. 8名を個別実施するための運用メモ

- **育成側の台本を1本に固定**：8回の説明内容がブレると、テストの公平性が崩れる
- **知識パートは録画教材化を推奨**：ブロック1・2は共通録画＋確認テストにすると、8回の品質が揃い、対面時間を実技に寄せられる
- **実施記録を1名1シート**：誤答項目・フィードバック内容・リテイク結果を残し、テスト時の確認ポイントに引き継ぐ
- **日程**：研修とテストの間隔は自主リハーサルが入る3〜7日が目安
- **不合格時の扱い**：再テストの回数・期限をあらかじめ決めておく（研修冒頭で明示する）

---

## 7. 確認が必要な事項

1. 8名それぞれの担当講座の割り当て（1名1講座か、複数講座を担当するか）
2. 担当形態（対面のみ／オンラインのみ／両方）— ブロック3の重点が変わる
3. 講座ラインナップの版の確定
   - 事業資料側：9講座・1回概ね2時間
   - LP（本サイト）側：10講座・90分／30分などの構成
   - どちらを正として講師に教えるかを確定する必要がある
4. 保有資格の内訳（健康運動指導士・管理栄養士等）— 栄養系講座を誰が担当できるか
5. 不合格時の再テスト運用
